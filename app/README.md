# Finance Feed

Next.js 15 + Upstash Redis + TradingView widgets.

## Deploy on Vercel
1. Push this folder to a GitHub repository and import it in Vercel (Framework Preset: Next.js).
2. Project > Storage > add Upstash Redis (KV_REST_API_URL / KV_REST_API_TOKEN are set automatically).
3. Settings > Environment Variables > add ADMIN_PASSWORD (long and unique).
4. Redeploy.

## Editor
Click the small dot in the footer, or open /admin, and sign in with ADMIN_PASSWORD.
